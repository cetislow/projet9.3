#  Explorateur de pays

Projet 9.3 — Akieni Academy — Phase 2 — Semaine 9

##  Présentation

**Explorateur de pays** est une application web permettant de
rechercher et d'explorer les pays du monde à partir de données
récupérées depuis l'API REST Countries.

Les données sont récupérées avec JavaScript puis manipulées côté
client afin de permettre la recherche, le filtrage et le tri.

Les pays sont présentés sous forme de cartes dans une grille
responsive.

---

##  Objectifs

Le projet permet de pratiquer :

- `fetch()` ;
- `async / await` ;
- `filter()` ;
- `map()` ;
- `sort()` ;
- `Promise.all()` ;
- la gestion des erreurs ;
- le traitement de données JSON ;
- la génération dynamique de HTML ;
- le responsive design.
